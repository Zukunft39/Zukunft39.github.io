# Tang Shaoyan / 唐劭岩 · Portfolio

静态个人作品集，适配 GitHub Pages。使用 HTML、CSS 与原生 JavaScript，无构建依赖。

## 浏览与预览

直接打开 `index.html`，或在此目录运行：

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8000/`。

## 页面

- `index.html`：首页，精选作品、实习实践、经历摘要、实验笔记与联系。
- `work.html`：按游戏、仿真、实习工具、课程实验筛选的作品目录。
- `journey.html`：教育、实习、项目与学习时间轴。
- `notes.html`：NUS 实验和学习入口。
- `projects/`：10 个项目／实践／实验详情页。
- `generic1.html`、`generic2.html`：保留旧入口，跳转到新版；旧项目锚点映射到对应详情页。
- `generic3.html`：保留原有 CS:GO 核心战斗体验拆解文档入口。
- `404.html`：不存在页面的返回入口。

## 维护

通用样式集中在 `assets/css/portfolio.css`，首页章节排版在 `assets/css/chapters.css`，交互集中在 `assets/js/portfolio.js`。精选图片和简历在 `assets/portfolio/`，沿用原仓库的其他资源无需删除。

导航使用透明角色头像与“硕糖 / HugeSugar”文字标识。头像为 `assets/portfolio/hugesugar-avatar.png`，浏览器标签图标为 `favicon-64.png` 与 `favicon.svg`；文字使用楷体／衬线字体及细描边，手机端会缩小。

正文使用静态 HTML，关闭 JavaScript 后仍可阅读并使用导航。交互包括移动菜单、作品筛选和原生图片对话框；支持键盘关闭、焦点返回与减少动态效果偏好。

首页分为序章和 01—05 五个章节，按视口安排独立页面，以垂直平滑滚动和轻微淡入淡出衔接。滚轮每次手势切换一章；触摸使用浏览器原生滚动吸附。章节导航、下一章、Page Up／Down、方向键及 Home／End 可切换位置。很矮的视口允许在本章内读完长内容；减少动态效果偏好会关闭自动翻页与渐变，保留普通滚动和章节链接。项目详情保持连续阅读。

详情页日期与目录组成同一侧栏：大号衬线数字突出年月，跨年项目分列起止日期，学期信息保留原有精度。桌面侧栏随阅读固定，手机端放在正文前。

## 内容与素材

只展示已确认的项目、职责与周期。团队画面按团队作品呈现，三维课设保留开源基础的说明。详情页包含规则／原理、实现流程、实验或设计对照、个人职责与反思；图片注明实际运行、设计稿或实验输出，支持点击放大。

素材来自项目文档、答辩、演示视频和保存的课程实验输出。腾讯原型界面以原始源码加载新建通用测试地图截图，自动化流程使用概念重绘。公开内容不含真实业务配置、内网链接、证明、申请材料或整套课程答案。课程结果未作为临床影像或真实飞行验证。

网站简历为中英文两页综合版：第 1 页为教育、技术项目与能力，第 2 页为实习、游戏设计与工具能力。导航和首页联系区均提供中文与 EN 入口；`Tang_Shaoyan_Resume.pdf` 保留为英文下载地址，中文为 `Tang_Shaoyan_Resume_CN.pdf`，两者均有同名 `.tex` 源码。

简历沿用 Jake’s Resume 的 A4 单栏 LaTeX 模板，当前 PDF 通过 ReportLab 等效排版生成，字体嵌入且正文可选择。下载文件采用最新确认的教育与项目时间，预计毕业时间按月份显示，仍为个人计划。
